## 🚀 皇上只需3步即可上线！

### 第1步：创建GitHub仓库（2分钟）

1. 访问：https://github.com/new
2. 仓库名填：`rushwei.github.io`（必须这样！）
3. 点击：Create repository

---

### 第2步：上传文件（3分钟）

1. 在新创建的仓库中，点击 "uploading an existing file"
2. 点击 "choose your files"
3. 选择 `index.html` 文件
4. 在底部 "Commit changes" 输入：`玄开悟-AI导航首次部署`
5. 点击绿色按钮：Commit changes

---

### 第3步：启用GitHub Pages（1分钟）

1. 在仓库页面，点击 Settings
2. 左侧菜单找到 Pages
3. Source 选择：Deploy from a branch
4. Branch 选择：main，文件夹：/ (root)
5. 点击 Save

## 🎨 自定义内容

### 添加新网站

在 `index.html` 中找到对应的分类，复制粘贴这个格式：

```html
<a href="网站地址" target="_blank" class="card">
    <div class="card-icon"><i class="fas fa-图标"></i></div>
    <div class="card-title">网站名称</div>
    <div class="card-description">网站描述</div>
</a>
```

### 可用图标（Font Awesome）

- 图像：fa-image, fa-paint-brush, fa-camera
- 对话：fa-robot, fa-comments, fa-brain
- 写作：fa-pen, fa-pencil, fa-edit
- 代码：fa-code, fa-cogs, fa-cube
- 学习：fa-book, fa-graduation-cap, fa-university
- 更多图标：https://fontawesome.com/icons
